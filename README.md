# Не сегодня (NotToday)

Минималистичный легковесный таск-менеджер для Android. Без аккаунтов, без сети, без аналитики — только задачи.

## Возможности

- Задачи на сегодня и на любые даты, экран календаря по месяцам
- Повторяющиеся задачи (день / неделя / месяц / год)
- Напоминания с точными будильниками; перестраиваются после перезагрузки, смены времени и часового пояса
- Вложения к задачам (с ограничением размера, открытие через FileProvider)
- Резервное копирование: экспорт и импорт локального файла бэкапа
- Темы: системная / светлая / тёмная
- Локализация: русский, английский, 中文（简体）

## Приватность

В приложении нет разрешения `INTERNET` — все данные хранятся только на устройстве. Системный автобэкап отключён (`allowBackup=false`), резервные копии создаются вручную и в собственном формате.

## Технологии

- Kotlin 2.4, Jetpack Compose, Material 3
- Room 2.8 (KSP), DataStore Preferences
- AlarmManager (точные будильники) + уведомления
- Min SDK 26 (Android 8.0), target/compile SDK 37
- Сборка: Gradle 9.3 (wrapper), JDK 17

Ключевой принцип — минимум кода и зависимостей: никакой DI, сети и лишних библиотек.

## Сборка

```bash
./gradlew assembleDebug   # сборка debug-APK
./gradlew test            # юнит-тесты
```

## Структура

```
app/src/main/java/com/dima/minimaltasks/
├── data/
│   ├── local/       # Room: сущности, DAO, база
│   ├── settings/    # DataStore: настройки и темы
│   ├── backup/      # экспорт/импорт бэкапов
│   └── ...          # репозитории, вложения
├── domain/          # расчёт повторений
├── notifications/   # напоминания: планировщик, приёмники, уведомления
├── ui/              # Compose: экраны, ViewModel, тема
└── ...
```

Схемы БД хранятся в `app/schemas/`.
